# 🎙️ TKStug VietTTS Studio & Automation Tools

> **Ứng Dụng Chuyển Đổi Văn Bản Thành Giọng Nói AI (64+ Giọng Tiếng Việt) & Tự Động Hóa Tải File Google Sheet / Google Drive**  
> *Professional Vietnamese AI Text-to-Speech Studio & Google Workspace Automation*

---

## ✨ Tính Năng Chính (Key Features)

### 1. 🎙️ VietTTS Studio (Chuyển Đổi Văn Bản Thành Giọng Nói AI):
- ⚡ **Hơn 64+ Giọng Đọc AI Chất Lượng Cao**: Đầy đủ giọng Bắc, Trung, Nam, giọng đọc truyện đêm khuya, podcast, tin tức thời sự,...
- 🎛️ **Tùy Chỉnh Chuyên Sâu**: Tùy chỉnh tốc độ đọc (Speed), cao độ giọng (Pitch), âm lượng (Volume).
- 🎵 **Trình Phát Âm Thanh Tích Hợp**: Nghe thử trực tiếp từng câu, tự động phân đoạn văn bản dài và xuất file MP3 / WAV chất lượng phòng thu.

### 2. 📊 Google Sheet & Google Drive Downloader:
- 🔗 Đọc dữ liệu hàng loạt từ Google Sheet theo cột.
- 🚀 Tự động quét và tải hàng trăm file từ Google Drive với tốc độ cao.
- 🛡️ Hỗ trợ tải bằng Browser Automation & Google Drive API OAuth2.

---

## 🛠️ Cài Đặt & Khởi Chạy (Installation & Run)

### 1. Cài đặt thư viện:
```bash
pip install PyQt6 edge-tts pygame requests google-auth google-auth-oauthlib google-api-python-client gspread playwright
```

### 2. Khởi chạy VietTTS Studio:
```bash
python main.py
```

### 3. Khởi chạy Google Sheet & Drive Downloader:
```bash
python main_downloader_gui.py
```
